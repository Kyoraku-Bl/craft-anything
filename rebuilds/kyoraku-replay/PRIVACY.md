# سياسة الخصوصية · Kyoraku Replay

**آخر تحديث: 2026-11-03** · عربي / Darija

> الخلاصة: **ما كنجمعو حتى بيانات شخصية.** ما كاين حساب، ما كاين إيميل، ما كاين كوكيز تتبّع، ما كاين سيرفر كيستقبل جلساتك.

---

## 1. شنو كيتخزّن، وفين؟

| البيانات | المكان | من كيقدر يشوفها |
|---|---|---|
| إعدادات الجلسة (رصيد، مخاطرة، وقف، trailing، إغلاق جزئي...) | `localStorage` فمتصفحك، مفتاح `kyoraku-replay:state:v2` | غير **أنت**، على نفس الجهاز + نفس المتصفح |
| الصفقات، الوسوم، الملاحظات، الجلسات المؤرشفة | نفس المكان | غير أنت |
| بيانات CSV اللي استوردتيها | نفس المكان (`state.customDatasets`) | غير أنت |
| اللغة (ar/en) وتبويب الواجهة | نفس المكان / الذاكرة | غير أنت |

**ما كاينش**: اسم، إيميل، كلمة سر، رقم هاتف، IP مسجّل عندنا، معرّف جهاز، ملف تعريف، ولا أي رفع سحابي. حتى `analytics`/`telemetry` ما كاين فالكود.

### التحقق بنفسك
- افتح DevTools → Application → Local Storage → كتشوف غير المفتاح فوق.
- `grep -RniE "cookie|gtag|analytics|pixel|track|session_id" js/ index.html` → ما كيلقى حتى شي (عدا وحدة `analytics.js` ديال الإحصاءات المالية المحلية).
- Network tab وقت الإقلاع: غير ملفات `index.html`, `css`, `js/*`, `data/catalog.js`، و `data/<ID>.js` إلى اخترتي سوق حقيقي.

## 2. الطلبات الشبكية (الاستثناء الوحيد، وبإذنك)

التطبيق **ما كيدير حتى `fetch` فالبداية**. الطلب الوحيد كيوقع غير إلى ضغطتي **«حمّل مباشر»** فتبويب «البيانات»:

```
متصفحك → /api/ohlcv?symbol=…&interval=…&range=…  (Vercel function على نطاقك)
        → query1.finance.yahoo.com/v8/finance/chart/…  (بيانات أسعار عامة)
```
أو، إلى ما كاينش الـ function (static hosting / `file://`):
```
متصفحك → api.allorigins.win/raw?url=<Yahoo URL>  (CORS relay عام)
```

فهادي الحالة:
- الطرف الثالث كيشوف **IP ديالك + الرمز اللي طلبتي + توقيت الطلب** فاللوجات ديالو (أمر طبيعي لأي HTTP request).
- **ما كنبعثوش** صفقاتك، ملاحظاتك، رصيدك، ولا أي شي من `localStorage`.
- النتيجة كتبقى **فذاكرة المتصفح للجلسة فقط**؛ ما كتخزّنش فـ `localStorage`، وما كترفعش لعندنا.
- الـ function عندها `Cache-Control: s-maxage=60` على الـ CDN ديال Vercel (كاش مؤقت لبيانات الأسعار العامة فقط).
- مزوّد الاستضافة (Vercel / Netlify / سيرفرك) كيحتفظ بلوجات HTTP العادية حسب سياسته هو — راجع سياسته إذا كنتي تنشر باسمك.

**إلى ما بغيتي حتى طلب**: خدّم غير البيانات المدمجة (`data/*.js`) و CSV ديالك، وما تضغطش «حمّل مباشر». التطبيق كيخدم 100% أوفلاين.

## 3. الكوكيز والتتبّع

- صفر كوكيز، صفر `localStorage` تتبّعي، صفر `sessionStorage` تتبّعي، صفر pixels، صفر SDK إعلاني، صفر fingerprints.
- المفتاح الوحيد هو الحالة ديال التطبيق (`kyoraku-replay:state:v2`) مع ترحيل اختياري من مفتاح قديم ديال نفس التطبيق (`replay-lab:state:v1`).

---

## 4. مسح / تصدير بياناتك

| بغيتي | كيدير |
|---|---|
| امسح كلشي | tab «البيانات» → **«امسح كل البيانات المحلية»** → كيمسح المفتاحين ويعاود يبدأ جلسة فارغة |
| احتفظ بنسخة | **«تصدير JSON»** (كلشي) / **«تصدير CSV»** (الصفقات) / **«تصدير PNG»** (الشارت) |
| استرجع | **«استيراد JSON»** |
| يدوياً | DevTools → Application → Local Storage → احذف `kyoraku-replay:state:v2` |

⚠️ `localStorage` كيمسح مع «مسح بيانات الموقع»، وضع التصفح الخاص، أو تبديل الجهاز/المتصفح. دير تصدير JSON قبلها.

## 5. الأطفال / القاصرين

التطبيق أداة تعليمية بلا حساب وبلا محتوى مخصّص للقاصرين. الاستعمال المقصود: التعلّم والمحاكاة تحت إشراف إلى لزم. ما كنطلبوش ولا كنخزّنو عمر ولا هوية.
