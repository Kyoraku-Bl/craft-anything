# 🦊 DimaLingo (ديما لينغو) — 100% Free Language-Learning PWA (A1 ➔ C2)

**DimaLingo** is a full-featured, **zero-cost, zero-paywall, zero-ads** Duolingo-inspired language-learning Progressive Web App (PWA) supporting **Arabic / Français / English** interfaces and four complete courses up to **CEFR C2 Mastery**:

- 🇬🇧 **English** (`A1` ➔ `A2` ➔ `B1` ➔ `B2` ➔ `C1` ➔ `C2`)
- 🇫🇷 **French** (`A1` ➔ `A2` ➔ `B1` ➔ `B2` ➔ `C1` ➔ `C2`)
- 🇪🇸 **Spanish** (`A1` ➔ `A2` ➔ `B1` ➔ `B2` ➔ `C1` ➔ `C2`)
- 🇲🇦 **Moroccan Darija (الدارجة المغربية الأصيلة)** (`A1` ➔ `A2` ➔ `B1` ➔ `B2` ➔ `C1` ➔ `C2`)

## ✨ Key Features (100% Free Forever)
1. **Full CEFR `A1` ➔ `C2` Curriculum + Jump-Ahead Placement Tests**:
   - All 4 courses span 6 full CEFR units from beginner (`A1`) to native-level rhetoric & proverbs (`C2`).
   - Built-in **Jump-Ahead Placement Tests** let experienced learners test directly into higher CEFR levels (`A2`, `B1`, `B2`, `C1`, `C2`).
2. **Live Microphone Speaking & Pronunciation Lab (`🎙️`)**:
   - Real-time microphone waveform visualizer (`AudioContext` + `AnalyserNode`), voice recording & self-playback (`MediaRecorder`), live speech recognition (`SpeechRecognition`), and word-by-word fuzzy Levenshtein pronunciation scoring across all 4 languages (including dual Arabic + Latin/Arabizi script recognition for Moroccan Darija!).
   - Dedicated **Speaking Lab** tab + **Speaking Nodes** inside every unit.
3. **Full Dark Mode (`🌙`)**:
   - Toggleable eye-friendly Dark Mode from the top header, onboarding screen, or profile settings — automatically persisted across sessions.
4. **Zero Paywalls (`∞ Unlimited Hearts` + Free Explain My Answer + Free SRS)**:
   - Unlimited Hearts enabled by default, Half-Life Regression spaced-repetition Practice Hub, instant grammar explanations, Streaks, Daily Quests, Leaderboards, and a Gems-only cosmetic shop.

## 🚀 Run Locally
